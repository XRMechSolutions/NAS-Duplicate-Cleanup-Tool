## Version History

### [1.0.0] - TBD

First public release.

#### Added
- File scanning across local and network drives (UNC paths)
- Exact duplicate detection via content hashing
- Near-duplicate image detection via perceptual hashing
- Cross-format duplicate detection (JPEG/PNG/HEIC)
- Multi-drive management with redundancy checking
- Photo organization by date, location, and events
- Smart file renaming based on EXIF metadata
- Face detection and recognition
- Age progression tracking (baby to adult)
- Scene and object classification
- Semantic search ("sunset at beach")
- Image quality scoring
- OCR for documents and screenshots
- Document version tracking with Git compression
- Quarantine, trash, and delete modes
- Complete action audit log
- Undo support for most operations
- Windows installer with auto-update
- Setup wizard for first-time users
- GPU acceleration for AI features
- Configurable logging levels
