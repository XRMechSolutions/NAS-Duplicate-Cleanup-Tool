# Files Tab - User Guide

## Overview

The **Files tab** is your file browser for exploring everything you've scanned. Navigate folders, view files, see summaries, and perform operations.

## Location

       ^^^^^^
     NEW TAB!

## How to Use

### 1. Navigate Folders

**Left Panel - Folder Tree:**
- 📁 Click folder to expand/collapse
- Click folder name to view its files
- Shows only scanned drives (from Drives tab)
- Hierarchical view of all subdirectories

### 2. Browse Files

**Right Panel - File Table:**
- Lists all files in selected folder
- Columns:
  - **Name** - Filename
  - **Size** - Human readable (KB, MB, GB)
  - **Modified** - Last modified date/time
  - **Type** - File extension
  - **Summary** - ✓ has summary | ✗ no summary

**Click a file** to view its details below

### 3. View File Details

**Bottom Panel - Details:**
Shows for selected file:
- Full path
- Size, modified date, file type
- **AI Summary** (if available)
- Model used and generation date

### 4. Perform Actions

**Action Buttons:**
- **Open File** - Opens in default system app (Windows Explorer, default image viewer, etc.)
- **Generate Summary** - Creates AI summary for this file (disabled if already has summary)
- **Unredact PDFs (Folder)** - Runs the external unredact tool on all PDFs in the selected folder (writes new files ending in `-unredact.pdf`)

## Features

### Status Indicators

File table shows summary status:
- **✓ Green** - File has AI summary
- **✗ Gray** - No summary yet

### Automatic Updates

- Tree refreshes when you scan new drives
- Click **Refresh** button to reload current view

### Smart Filtering

- Only shows files in exact folder (not subdirectories)
- Excludes deleted files
- Sorted alphabetically by name

## Tips

### Finding Files

- Use tree to navigate hierarchically
- Current folder shows in header
- File count shows next to "Files" header

### Managing Summaries

- **Bulk summarization**: Use Drives tab "Generate Summaries for Folder"
- **Single file**: Select file, see if it has summary
- **View summary**: Click file to see full text in details panel

### Performance

- Tree loads lazily (subfolders load on expand)
- Limited to 50 subfolders per level (prevents huge trees)
- Files load only when folder selected

## Integration with Other Tabs

### From Drives Tab

1. Scan a drive (Drives tab)
2. Go to Files tab
3. Browse what was scanned

### To Summary Generation

1. Find folder in Files tab
2. Note the path
3. Go to Drives tab → "Generate Summaries for Folder"
4. Paste the path
5. Generate summaries
6. Return to Files tab to see ✓ indicators

### To Search

1. Files with summaries are searchable
2. Go to Search tab
3. Search for content
4. Results link back to files

## Troubleshooting

### "No drives scanned yet"

**Cause:** No drives added in Drives tab

**Solution:**
1. Go to Drives tab
2. Add a drive
3. Run scan (Quick/Deep/Full)
4. Return to Files tab
5. Click Refresh

### Tree shows drive but no subfolders

**Cause:** Drive is empty or has no subdirectories

**Solution:**
- Verify drive path is correct
- Check if files exist directly in drive root (they'll show in file list)

### File table is empty

**Cause:** Selected folder has no files (only subdirectories)

**Solution:**
- Expand subfolder in tree
- Look deeper in folder hierarchy
- Files might be in subdirectories

### Summary shows "No summary available"

**Cause:** File hasn't been summarized yet

**Solution:**
1. Note the folder path
2. Go to Drives tab
3. Use "Generate Summaries for Folder"
4. Enter this folder's path
5. Generate summaries
6. Return to Files tab and refresh

### "Generate Summary" button disabled

**Cause:** File already has a summary

**Solution:**
- Summary already exists - read it in details panel
- To regenerate, use Drives tab with "Re-analyze" option

### "Unredact PDFs (Folder)" button disabled

**Cause:** External unredact tool not found or no PDFs in the folder

**Solution:**
1. Ensure the tool exists at `C:\Users\clint\unredactFiles\src\unredact.py`
2. Or set `DUPLICLEANER_UNREDACT_PATH` to the full path of `unredact.py`
3. Refresh the Files tab
